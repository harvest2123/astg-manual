指揮系統の基本

命令は上位から下位へ

指揮権や命令は、基本的に上位の指揮官から下位へ順番に伝えられます。隊員は原則として、直属の上官から命令を受けます。

階級と任務上の役職・指揮権は区別します。任務中は指定された指揮官と指揮系統に従い、階級だけで指揮権を引き継いだり、他部隊へ直接指示したりしないでください。

直属の上官を通じた伝達

たとえば、Baker小隊・A分隊・第1班に所属している場合は、次の流れになります。

Baker小隊長の作戦方針 → A分隊長の命令 → 第1班長の具体的な指示 → 各隊員

細かい行動の指示は、基本的に直属の上官から受けます。

この例の「Baker小隊」は提供本文の呼称です。組織図の「Baker Company（中隊）」とは階層が異なるため、実際の活動ではその時点で指定された所属・編成を確認してください。

命令が重なった場合

複数の命令が同時に出て内容が食い違う場合は、指定された指揮系統の中で、より上位の指揮官の命令を優先します。ただし、部隊規則に反する命令は優先せず、部隊規則第5条に従ってOISへ報告してください。判断に迷う場合は、直属の上官に確認し、どの命令を受けたかを共有してください。

指揮官が行動できなくなった場合

ゲーム内での死亡・離脱・通信不能などの場合は、事前に決めた順番で指揮を引き継ぎます。

継承順の例：1-1 → 1-2 → 1-3 → 1-4 …

この番号は継承順を示す例です。行動開始前に代行者と順番を確認し、交代した際は部隊内で共有しましょう。

具体的な引継ぎ手順は指揮官実務マニュアル・第6章を参照してください。
